NeoCare NICU Management & Neonatal Telemetry System - Windows Installer
========================================================================

How to install on another PC or laptop:
1. Copy the file "NeoCare Setup 1.0.0.exe" to a USB drive or upload it to Google Drive / OneDrive.
2. Transfer it to any computer running Windows 10 or Windows 11.
3. Double-click "NeoCare Setup 1.0.0.exe" to begin installation.
4. Follow the on-screen installer prompts:
   - You can choose the installation folder or accept the default.
   - It will automatically create a Desktop Shortcut ("NeoCare NICU") and a Start Menu icon.
5. Launch the application from your Desktop or Start Menu.
6. Sign in with your registered hospital account (Doctor, Nurse, Hospital In-Charge, or System Admin).

System Requirements:
- Operating System: Windows 10 / Windows 11 (64-bit)
- Internet connection: Required to stream real-time vitals from the cloud backend
- No programming tools, Node.js, or prerequisites required!
